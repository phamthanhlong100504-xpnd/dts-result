# Tài liệu DTS Result

Đọc [LOCAL_SETUP](LOCAL_SETUP.md) để chạy repo, [RESULT_FEATURES](RESULT_FEATURES.md) để hiểu nghiệp vụ và [API blueprints](api-blueprint/README.md) để nối frontend. [Migration catalog](db/MIGRATION_CATALOG.md) phân biệt schema V001–V004 với data maintenance thực hiện riêng.

Tài liệu mới mô tả code đang bàn giao: History có source routing/release/ownership, dedup và summary rebuild, EXP evidence, public profile consumer riêng, leaderboard và analytics. [Screen14/16 contract](api/SCREEN14_16_BACKEND.md) được giữ nguyên. [learning-result-processing](learning-result-processing.md) và [summary-projection](summary-projection.md) đã cập nhật theo nhánh hiện tại.

Các file context/plan của nền repo được giữ; chúng không thay thế contract hiện hành. docs/db/SCREEN12_SCHEMA.md có checksum cố định nên phần bổ sung nằm riêng, không sửa file đó để cập nhật tài liệu.
