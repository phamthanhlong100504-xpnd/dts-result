# result-service-stage-5-6-blueprint.md

# Result Service Blueprint — Stage 5 & Stage 6

## Mục tiêu

Sau Stage 3 và Stage 4, Result Service đã hoàn thành:

* Kafka Consumer
* Xử lý learning_results
* Projection learning_summaries

Stage 5 và Stage 6 triển khai **REST APIs phục vụ frontend và các service khác**.

* **Stage 5:** History APIs (Attempt History)
* **Stage 6:** Summary / Progress APIs (Projection Read Model)

Tất cả API trong giai đoạn này là **read-only**.

Result Service **không có API ghi dữ liệu**.

---

# Stage 5 — History APIs

## Mục tiêu

Cung cấp API truy vấn **lịch sử học tập / lịch sử làm bài** của người dùng.

Nguồn dữ liệu:

`learning_results`

Mỗi record tương ứng với **một lần thực hiện (attempt)**.

---

## API List

### GET /v1/results/me/history

Lấy danh sách lịch sử thực hiện.

### GET /v1/results/me/history/{resultId}

Lấy chi tiết một lần thực hiện.

### GET /v1/results/me/recent

Lấy hoạt động gần đây.

---

# API 1 — Get History List

## Endpoint

```text
GET /v1/results/me/history
```

## Authentication

JWT Required

User ID được lấy từ Access Token.

Không nhận userId từ client.

---

## Query Parameters

| Field      | Required | Description                                   |
| ---------- | -------- | --------------------------------------------- |
| targetType | No       | EXAM, CHAPTER, LESSON, LEARNING_PROGRAM       |
| targetId   | No       | ID đối tượng học                              |
| result     | No       | PASSED, FAILED, COMPLETED, ABANDONED, EXPIRED |
| from       | No       | Thời gian bắt đầu                             |
| to         | No       | Thời gian kết thúc                            |
| page       | No       | Default = 0                                   |
| size       | No       | Default = 20                                  |
| sort       | No       | Default = completedAt,desc                    |

---

## Business Rules

* Chỉ trả dữ liệu của user hiện tại.
* Có thể filter theo targetType.
* Có thể filter theo targetId.
* Có thể filter theo result.
* Có thể filter theo khoảng thời gian.
* Có phân trang.
* Kết quả được sắp xếp theo `completedAt DESC`.

---

## Processing Flow

```text
Controller
     |
     v
HistoryService
     |
     v
LearningResultRepository
     |
     v
learning_results
```

---

## Repository Query

Filter theo:

* user_id
* target_type
* target_id
* result
* completed_at

Order:

`completed_at DESC`

---

## Response

```json
{
  "content": [
    {
      "id": "uuid",
      "targetType": "EXAM",
      "targetId": "uuid",
      "attemptNo": 3,

}
```

# API 3 — Get Recent Activities

## Endpoint

```text
GET /v1/results/me/recent
```

## Query Parameters

| Field | Required | Description  |
| ----- | -------- | ------------ |
| limit | No       | Default = 10 |

---

## Business Rules

* Trả các hoạt động gần nhất.
* Order theo `completedAt DESC`.
* Không phân trang.

---

```text
Find learning_results

LIMIT limit
```

# Stage 6 — Summary / Progress APIs

## Mục tiêu

Cung cấp API truy vấn **projection hiện tại của người học**.

Nguồn dữ liệu:

`learning_summaries`

Đây là API được frontend gọi nhiều nhất.

Phục vụ:

* Danh sách đề thi
* Danh sách chapter
* Danh sách lesson
* Danh sách learning program
* Progress bar
* Resume learning
* Dashboard progress

---

## API List

### GET /v1/results/me/summaries

Danh sách projection.

### GET /v1/results/me/summaries/{targetType}/{targetId}

Chi tiết projection.

### GET /v1/results/me/summaries/status

Thống kê theo trạng thái.

### GET /v1/results/me/summaries/progress

Tiến độ theo loại đối tượng.

### GET /v1/results/me/summaries/resume

Đối tượng học cần tiếp tục.

---

# API 8 — Get Resume Target

## Endpoint

```text
GET /v1/results/me/summaries/resume
```

## Business Rules

Trả đối tượng học nên tiếp tục.

Ưu tiên:

1. status = IN_PROGRESS
2. lastActivityAt DESC
3. progress DESC

Nếu không có đối tượng đang học:

→ trả null.

---

## Processing

```text
Find summaries

status = IN_PROGRESS

ORDER BY

lastActivityAt DESC,

progress DESC

LIMIT 1
```

---

## Response

```json
{
  "targetType": "LESSON",
  "targetId": "uuid",
  "progress": 65,
  "lastActivityAt": "2026-08-04T10:00:00Z"
}
```

# Completion Criteria

## Stage 5

* GET /history hoạt động
* GET /history/{id} hoạt động
* GET /recent hoạt động
* Pagination đúng
* Filtering đúng
* Ownership check đúng

## Stage 6

* GET /summaries hoạt động
* GET /summaries/{target} hoạt động
* GET /summaries/status hoạt động
* GET /summaries/progress hoạt động
* GET /summaries/resume hoạt động
* Projection query đúng
* Status aggregation đúng
* Resume logic đúng

Sau Stage 6, Result Service cung cấp đầy đủ **History APIs và Progress/Summary APIs**, đủ để frontend xây các màn hình:

* Lịch sử làm bài
* Chi tiết kết quả
* Danh sách đề thi
* Danh sách chapter
* Danh sách lesson
* Danh sách learning program
* Progress theo từng đối tượng học
* Resume learning
* Dashboard progress.
